# Roadmap (post-v1)

Items here are **out of scope for v1.0.0** ([PLAN §14](PLAN.md)). They are listed with the groundwork v1 leaves in place, so they can be added without rewrites. Nothing in this file is implemented yet.

| Item                                                                                            | Why                                                                          | Groundwork in v1                                                                                                                  |
| ----------------------------------------------------------------------------------------------- | ---------------------------------------------------------------------------- | --------------------------------------------------------------------------------------------------------------------------------- |
| **Financial module** (tuition, Pix, boletos) for private schools                                | Most private schools still pay for a separate ERP                            | `tenants.network` distinguishes private schools; plans and feature flags (below) gate the module; audit categories are extensible |
| **Educacenso export**                                                                           | Mandatory annual census for public schools                                   | Structured `students`, `enrollments` (lifecycle events), `classes` (stage, shift) and `subjects`                                  |
| **Attendance reports for condicionalidades** (e.g., Bolsa Família)                              | Public networks must report attendance of beneficiaries                      | Daily attendance per lesson; legal attendance % from the domain engine ([ADR-0005](adr/0005-grade-engine-and-scales.md))          |
| **Opt-in AI assistant per school** (draft announcements, a student summary for parent meetings) | Saves teacher and secretaria time                                            | Domain data is already structured; the assistant must use **minimized and anonymized** data and be off by default per tenant      |
| **Annual closing, final recovery and conselho de classe**                                       | v1 shows the annual result for information only (owner decision, 2026-10-06) | Weighted annual average and situation in `src/domain`; `terms.weight`; the audit trail for decisions                              |
| **Direct concept entry** (A–E)                                                                  | v1 always enters numbers; concepts are shown through bands                   | Normalized storage and configurable `concept_bands` ([ADR-0005](adr/0005-grade-engine-and-scales.md))                             |
| **Native app**                                                                                  | Push and offline support beyond the PWA                                      | API-first data access through Supabase; the PWA proves the offline flows                                                          |
| **Dark mode**                                                                                   | Accessibility and preference                                                 | All colors are CSS variables in `src/styles/tokens.css`; a theme only overrides that layer                                        |
| **Plans and per-tenant feature flags**                                                          | Commercial packaging                                                         | `school_settings` per tenant; each feature checks a flag before it renders                                                        |
| **SSO** (Google Workspace for Education, gov.br)                                                | Lower friction for networks                                                  | Identity is decoupled from memberships ([ADR-0003](adr/0003-authentication-and-identity.md))                                      |
| **External anchoring of audit chain heads**                                                     | Detect a full, consistent rewrite of the database                            | Per-tenant hash chain with `verify_chain` ([ADR-0004](adr/0004-append-only-audit-log.md))                                         |
| **Per-visitor ephemeral demo tenants**                                                          | Visitors would not see each other's changes                                  | A separate demo project with a scripted, date-relative seed ([ADR-0006](adr/0006-environments-and-demo.md))                       |
| **Per-tenant query and rate limits**                                                            | Stop a noisy neighbor from slowing other schools on the shared database      | The Postgres rate limiter (`private.rate_limit_hit`)                                                                              |
| **i18n**                                                                                        | Spanish-speaking markets                                                     | UI copy is concentrated in components; formatters are centralized in `src/domain` and `src/lib/format`                            |
| **Magic-link login for guardians**                                                              | Families that forget passwords                                               | Invitation flow and email infrastructure from M2                                                                                  |
